# Interfaz (dashboard web)

El dashboard del docente es una página web que sirve el servidor con Flask. Su código está en [`servidor/templates/index.html`](../servidor/templates/index.html), porque Flask busca ahí las plantillas.

Se abre desde el navegador del celular o la computadora, en la misma red WiFi que el servidor:

```
http://IP-DE-LA-PC:5000
```
